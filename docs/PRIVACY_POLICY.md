# Política de privacidad de ShareToLocate

Última actualización: 1 de agosto de 2026.

ShareToLocate comparte ubicación exclusivamente con contactos que el usuario añade y verifica. La aplicación no requiere cuenta, correo electrónico ni número de teléfono.

## Datos tratados

- Ubicación precisa, únicamente mientras el usuario activa la compartición.
- Identidad criptográfica Tox y lista de contactos, almacenadas localmente.
- Alias elegidos por el usuario y últimas posiciones recibidas.

## Transmisión

Las ubicaciones se transmiten cifradas de extremo a extremo mediante toxcore. Los nodos DHT y relays ayudan a establecer o transportar conexiones, pero no reciben las claves necesarias para interpretar el contenido.

## Conservación y terceros

La aplicación no incorpora publicidad ni analítica y no vende datos. La identidad y configuración permanecen en el dispositivo hasta que el usuario elimina la aplicación o sus datos. Los mapas se descargan de OpenStreetMap y pueden revelar al proveedor de teselas la dirección IP y el área visualizada.

## Permisos

La ubicación precisa permite obtener la posición. El servicio en primer plano y las notificaciones hacen visible cualquier sesión activa. La ubicación en segundo plano solo se utiliza cuando el usuario mantiene una sesión de compartición.

## Contacto

Antes de publicar la aplicación, el responsable deberá sustituir esta sección por un correo o URL de soporte real.
